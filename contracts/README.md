# Foundry training contracts

These fixtures demonstrate accounting, access control, checks-effects-interactions, a simple reentrancy guard, unit tests, fuzz tests, and an invariant.

Install Foundry and fetch its test library:

```bash
cd contracts
forge install foundry-rs/forge-std --no-commit
forge test -vv
```

Do not deploy these examples with real funds. The test suite is educational and is not a substitute for an audit.
