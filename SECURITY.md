# Security Policy

BlockSentinel is experimental security triage software, not an audit.

## Reporting
For repository vulnerabilities, use GitHub's private vulnerability reporting where available. Avoid publishing exploitable details about third-party deployed systems before responsible disclosure.

## Safe operation
- Keep confidential source analysis local.
- Never submit private keys, seed phrases, tokens, or credentials.
- Do not expose Slither/compiler execution to arbitrary internet users without sandboxing.
- Treat all results as hypotheses requiring independent validation.
